Повторный чистый прогон (свежая загрузка, без интерактивного шума) — консоль чистая. Не чинилось за неимением воспроизводимого случая; если всплывёт снова — смотреть в первую очередь на взаимодействие быстрых повторных кликов по избранному (несколько параллельно запланированных `schedulePriceDropDemo`-таймеров) с состоянием bell
