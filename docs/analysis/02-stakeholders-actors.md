## 1. Стейкхолдеры

| Стейкхолдер | Интерес / цель | Влияние | Как учтён в продукте |
|-------------|---------------|---------|----------------------|
| **Покупатель б/у авто** | Найти надёжный автомобиль по справедливой цене, не потратить время на фрод | Высокое | Главный потребитель Deal Rating, ML-флагов, расширенного отчёта |
| **Частный продавец** | Быстро и дорого продать авто, привлечь серьёзных покупателей | Высокое | AI-рекомендация цены, верификация = доверие, управление объявлениями |
| **Автосалон / дилер** | Массовое управление объявлениями, аналитика, статус «Официальный дилер» | Среднее | P2: кабинет дилера (FR-19) |
| **Команда Carsale (бизнес)** | Монетизация, рост MAU, ликвидность платформы, LTV/CAC > 3 | Высокое | North Star метрика, план монетизации в Фазе 1 |
| **Команда Carsale (ML/Data)** | Качество моделей, достаточность данных, скорость inference | Среднее | ML-pipeline, seed-датасет, переобучение на реальных данных |
| **Агентство по персональным данным (UZ)** | Соблюдение ЗРУ-547: локализация данных, регистрация оператора | Высокое | NFR-11, NFR-12, NFR-13; хостинг в юрисдикции UZ |
| **ГУБДД / Страховые компании UZ** | B2G-партнёрство по предоставлению данных об истории авто | Среднее | FR-12 (P1); критический путь переговоров |
| **Click / Payme** | Корректная интеграция, соблюдение PCI DSS | Среднее | FR-10; PCI DSS через шлюз |
| **Eskiz UZ (SMS-шлюз)** | Стабильная доставка OTP | Низкое | FR-01; ADR-001 |
| **Конкурент Avtoelon** | Мониторинг рынка | — | Контекст стратегии: не лобовая атака, а нишевый дифференциатор |

## 2. Актёры системы

Актёры участвуют в use case модели ([03-use-case-model.md](03-use-case-model.md)). Имена строго согласованы с UC-документом.

| Актёр | Тип | Описание | Основные цели |
|-------|-----|----------|--------------|
| **Гость** (Guest) | Человек (внешний) | Неаутентифицированный посетитель | Просматривать каталог, Deal Rating, карточки авто |
| **Покупатель** (Buyer) | Человек (внешний) | Зарегистрированный, ищет авто | Искать, сохранять, связываться с продавцом |
| **Продавец** (Seller) | Человек (внешний) | Зарегистрированный, продаёт авто | Размещать объявления, получать AI-цену, общаться |
| **Верифицированный продавец** (VerifiedSeller) | Человек (внешний) | Продавец, прошедший SMS + OneID | Пользоваться приоритетом выдачи, бейджем «Проверен» |
| **Дилер** (Dealer) | Человек (внешний, P2) | Юр. лицо, управляет портфелем авто | Массовая загрузка, аналитика, статус «Официальный дилер» |
| **Администратор** (Admin) | Человек (внутренний) | Сотрудник Carsale | Модерировать фрод-флаги, управлять пользователями, видеть аналитику |
| **ML-сервис** (MLService) | Система (внутренняя) | Набор ML-моделей: Deal Rating, Blur, Mileage, Fraud | Асинхронная обработка объявлений, inference по запросу |
| **SMS Gateway (Eskiz UZ)** | Система (внешняя) | SMS-провайдер Узбекистана | Доставка OTP в течение 30 секунд |
| **Платёжный шлюз (Click/Payme)** | Система (внешняя) | PCI DSS-совместимый шлюз | Проведение платежей, возврат статуса транзакции |
| **OneID (gov.uz)** | Система (внешняя, P1) | Государственная ID-система UZ | Верификация личности продавца |
| **ГУБДД / Страховые API** | Система (внешняя, P1) | Источник данных истории авто | Данные о ДТП, штрафах, растаможке |
| **LLM API (Claude / OpenAI)** | Система (внешняя, P1) | LLM-провайдер | Генерация описаний, перевод, чат-бот |
| **Email-провайдер (SendGrid/SES)** | Система (внешняя) | Транзакционная почта | Уведомления, квитанции, алерты |
| **Push-сервис (Firebase/WebPush)** | Система (внешняя) | Браузерные push-уведомления | Алерты о ценах, сообщения чата |
| **CDN** | Система (внутренняя/внешняя) | Раздача фото объявлений | Быстрая загрузка медиа |
| **Планировщик (Scheduler)** | Система (внутренняя) | Cron-задачи | Обновление Deal Rating, отправка отложенных алертов |

### Правила смены роли

```
Guest → Покупатель         : регистрация + подтверждение SMS OTP
Покупатель → Продавец      : автоматически при первом размещении объявления
Продавец → ВерифицированныйПродавец : успешная верификация через OneID (P1)
Продавец → Дилер           : отдельный процесс B2B онбординга (P2)
```
