# ADR-003: Стратегия ML seed-датасета — синтетическая генерация

- **Статус:** Принято
- **Дата:** 2026-06-28
- **Автор:** Системный аналитик

---

## Контекст

ML-модели Deal Rating (FR-09), детекция скрученного пробега (FR-10) и детекция фрода (FR-11) требуют обучающих данных до публичного запуска платформы. На момент старта реальных данных объявлений на платформе нет.

Ограничения:
- Парсинг данных конкурентов (Avtoelon) — правовой риск, неустойчивые источники
- Покупка готового датасета — дорого, не специфично для UZ-рынка
- Ожидание накопления органических данных — Deal Rating недоступен в MVP

---

## Решение

**Синтетическая генерация** seed-датасета для Deal Rating:

1. **Источники для ценовых диапазонов:** открытые данные (публичные прайс-листы UZ-дилеров, агрегаторы типа Drom.ru/uz, открытые источники о ценах авто в СНГ), статистика UZ Автопрома
2. **Генерация:** для каждой популярной комбинации (марка × модель × год × состояние × регион) генерируется распределение цен (медиана + σ)
3. **Аугментация:** добавление шума, выбросов (для обучения детекции аномалий)
4. **Дообучение:** с первого дня запуска модели дообучаются на реальных данных платформы (инкрементальное обучение, переобучение по достижении 1000 реальных объявлений)

**Для детекции скрученного пробега:**
- Rule-based начальная логика: средний пробег ~15 000 км/год; существенное отклонение = флаг
- Переход к ML-модели при накоплении исторических данных по VIN

**Для fraud detection (image hash):**
- Алгоритм не требует датасета: perceptual hashing (pHash/dHash) — детерминированный

---

## Последствия

**Что становится проще:**
- MVP запускается с Deal Rating с первого дня
- Нет зависимости от внешних источников данных
- Модели начинают улучшаться органически с ростом объявлений

**Что становится сложнее:**
- Первые 1–3 месяца: MAPE может превышать 15% на редких моделях авто
- Синтетика ≠ реальность: распределение цен может быть смещено
- Нужен механизм мониторинга качества модели в production (MAPE drift alert)

**Митигация:**
- Если MAPE > 15% после 1 мес. — Deal Rating временно показывается только для топ-50 популярных моделей (где данных достаточно)
- A/B тест пользовательской ценности Deal Rating до и после дообучения

---

## Рассмотренные альтернативы

| Альтернатива | Причина отклонения |
|-------------|-------------------|
| **Парсинг Avtoelon** | Правовой риск (ToS); нестабильный источник; антипарсинг защита |
| **Покупка готового датасета** | Нет готовых датасетов для UZ-рынка авто; дорого |
| **Ожидать органического роста** | Deal Rating недоступен в MVP → потеря дифференциатора |
| **Human labelling (краудсорсинг)** | Медленно; требует бюджет и разметочную команду |
