# ADR-005: Web-first архитектура — нет мобильного приложения в MVP

- **Статус:** Принято
- **Дата:** 2026-06-28
- **Автор:** Системный аналитик

---

## Контекст

Рынок Узбекистана высоко мобилизован (большинство трафика с мобильных устройств). Конкурент Avtoelon имеет iOS и Android приложения. Вопрос: нужно ли мобильное приложение в MVP?

Ограничения MVP:
- Ограниченный инженерный ресурс
- Время выхода на рынок (time to market) критично
- iOS/Android = 2 отдельных кодовых базы (или React Native / Flutter)
- App Store / Google Play review процесс может занять 1–2 недели

---

## Решение

**Только веб-приложение (Next.js, адаптивная вёрстка) в MVP.** Мобильное приложение — Фаза 3 (после доказанной ликвидности).

**Компенсирующие меры:**
- Адаптивная вёрстка от 360px (NFR-24): мобильный браузер — полноценный experience
- PWA (Progressive Web App): возможность «установить» на домашний экран; offline-кэш статики
- Оптимизация LCP на 3G (NFR-4): главная < 2 сек на мобильном соединении

---

## Последствия

**Что становится проще:**
- Единая кодовая база → 2–3 месяца экономии разработки
- Один deployment pipeline
- Быстрее итерация: не нужен App Store review для каждого релиза
- SEO: Next.js SSR позволяет индексировать объявления в Google

**Что становится сложнее:**
- Ограниченные возможности push-уведомлений (Web Push; не все Android/iOS поддерживают одинаково)
- Нет доступа к нативной камере для загрузки фото (решается через `<input type="file" accept="image/*" capture>`)
- Конкурент Avtoelon с app — риск UX-сравнения не в пользу Carsale

**Митигация:**
- PWA bridge для push (Firebase Web Push покрывает Chrome Android; Safari поддерживает с iOS 16.4)
- Фокус на Web-опыте: карточки авто, Deal Rating, чат — работают отлично в mobile Chrome
- Мониторинг: если MAU конвертация < 50% (вероятно из-за отсутствия app) → планирование React Native в Фазе 3

---

## Рассмотренные альтернативы

| Альтернатива | Причина отклонения |
|-------------|-------------------|
| **React Native (cross-platform app)** | +2–3 мес. на разработку; нужен отдельный мобильный разработчик; задержка выхода |
| **Flutter** | Аналогично React Native; меньше JS-ресурсов в UZ рынке |
| **Native iOS + Android** | 4–6 мес. дополнительно; 2 кодовые базы; несовместимо с MVP-сроком |
| **Отдельная web + отдельная app** | Дублирование логики; слишком много ресурсов |
